Why We Recommend GCP:

1. Cost: GCP has the most generous free tier for auto scaling serverless containerized applications (this is what your chatbot will be when it is deployed to the cloud), in part because it can "scale your compute to 0", which is just a technical way of saying that when your app is not being accessed, it won't run, and you won't be billed. When a user access your app, it will run, but it takes a considerably amount of use before you get billed.  In an upcoming release of this project, we will breakdown the potential associated cost of using a chatbot at meaningful scale, but know that for most use cases we are currently envisioning, the cost to run the project on Google Cloud is effectively $0.00.
2. GCP is arguably the most user friendly of the 3 major platforms cloud, with an intuitive UX and streamlined services. This includes set up, which can be done with an existing Gmail address for social login. There are other UX/UI features that we've discovered through experimentation, and when relevant, we will make note of them.
3. Finally, new GCP accounts get $300 credits that can go towards using Gemini for API calls through a service used in this template called Gemini Enterprise Agent Platform. This means that there is no cost to using the Gemini API for the first $300 of use. This is completely unheard of with OpenAI and Claude, and means that the cost of users interacting with your project is covered for the 3 months these credits are available.
